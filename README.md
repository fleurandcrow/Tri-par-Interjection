# Tri-par-Interjection

What if your sort method was widly inefficient, so inefficient that the complexity of the algorithm end up being more than exponential?

## Disclaimer

This project is not made to be used in any serious projects, doing so will significantly slow down the execution of your code.

When I tested this on my own machine with a list of 200 elements, it took 10 minutes to execute and got my fans spinning. Compared to a traditional sort method, which basically finished executing instantly. 

This project is simply an experiment to see what could be the worst way possible for sorting a list.

## Programming languages

The project is currently only available in Python, however there are plans to add a version of the algorithm for C, C++ and C#.
